# data/ (repo root)

Reserved top-level data directory per the requested project layout. The actual demo data used by
the running application lives in [`backend/app/data/demo_data/`](../backend/app/data/demo_data/)
(generated by `backend/app/data/generate_demo_data.py`), since it needs to be importable by the
backend package. This root-level folder is kept empty as a placeholder for any future
externally-sourced datasets (e.g. a real historical market-data export).
