# Dev-only extras NOT installed in the production Docker image (backend/requirements.txt),
# to keep the deployed image small and within free-tier hosting limits.
#
# torch is used ONLY by backend/app/cv_engine/models/train.py to generate the synthetic
# financial-chart dataset and train the CNN / ViT-lite classifiers once during development.
# The resulting metrics/confusion-matrices/sample-predictions are saved as static JSON
# (backend/app/data/model_results/) and served by the API without needing torch at runtime.
# If torch happens to be installed in a given environment, the API will also offer live
# inference on a freshly uploaded image; otherwise it serves the precomputed results and
# says so explicitly.
#
# onnx is used ONLY by app/cv_engine/vision/train.py to export the trained classifier/Siamese-
# encoder PyTorch models to ONNX. The exported .onnx files (committed under
# app/data/model_results/vision/) are then served in production via opencv-python's cv2.dnn
# ONNX runner -- so production needs neither torch nor onnx, only opencv-python-headless
# (already in requirements.txt).
#
# Install with: pip install -r requirements-dev.txt --extra-index-url https://download.pytorch.org/whl/cpu
-r requirements.txt
